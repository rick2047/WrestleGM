## ADDED Requirements

### Requirement: README includes OpenSpec quickstart
The README MUST include a short OpenSpec section that explains where specs live and how to use the core OpenSpec commands.

#### Scenario: Contributor reads README
- **WHEN** a contributor scans the README
- **THEN** they can see where OpenSpec artifacts live
- **AND** they can identify the commands to start, continue, apply, verify, and archive a change
